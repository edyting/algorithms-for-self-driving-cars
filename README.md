# Algorithms for Self-Driving Cars

Notes and code from my study of probability, Bayesian reasoning, and the algorithms behind autonomous vehicles.

## Overview

I'm working through the algorithms behind self-driving cars, starting with the math. Right now that means Bayesian algorithms and the role of probability in autonomous driving. I'm taking an Introduction to Probability course first, then Bayesian Algorithms for Self-Driving Cars on edX.

Alongside the coursework, I write structured notes, work through examples, and implement the algorithms in code.

## Objectives

- Learn probability and Bayesian reasoning.
- See how probabilistic algorithms let a vehicle interpret uncertain information.
- Study filtering, state estimation, localization, and sensor fusion.
- Write clear notes on each concept and where it applies.
- Turn the math into code.
- Look at how these algorithms feed into perception, tracking, and decision-making.

## Roadmap

The order may change as I go.

1. Probability and statistics: probability basics, conditional probability, Bayes' theorem.
2. Probabilistic representations: histograms, probability distributions, uncertainty.
3. Bayesian inference: updating beliefs from observations.
4. Filtering algorithms: histogram, Kalman, and particle filters.
5. Localization and state estimation: estimating a vehicle's position and state under uncertainty.
6. Sensor fusion: combining data from multiple sensors.
7. Implementation: code examples, experiments, and analysis of results.

## Repository Structure

- `notes/`: structured notes, math explanations, and worked examples.
- `code/`: algorithm implementations.
- `examples/`: demonstrations and experiments.
- `resources/`: references and supplementary material.

## Notes Format

Each topic covers:

- The core concept and the problem it addresses.
- The math and key equations.
- Step-by-step explanations and worked examples.
- How it applies to autonomous driving.
- Code and experimental observations, where they apply.
